# ตัวอย่างงานเรียงความภาษาไทย

เอกสารนี้เป็นตัวอย่างสั้นสำหรับตรวจว่า workflow สามารถสร้างเอกสารภาษาไทยที่อ่านได้จริง จัดหน้า A4 ได้ถูกต้อง และคงรูปแบบย่อหน้าได้ครบ

## หัวข้อ: การเรียนรู้จากความผิดพลาด

ความผิดพลาดเป็นส่วนหนึ่งของการเรียนรู้ เพราะทำให้เราเห็นจุดที่ควรปรับปรุงอย่างชัดเจน เมื่อทำงานแล้วพบข้อบกพร่อง เราควรหยุดทบทวนสาเหตุ แยกสิ่งที่ควบคุมได้ออกจากสิ่งที่ควบคุมไม่ได้ และเลือกวิธีแก้ไขที่เหมาะสมแทนการโทษตนเองหรือผู้อื่น

การเรียนรู้ที่ดีไม่ได้หมายถึงการไม่ผิดพลาดอีกเลย แต่หมายถึงการไม่ทำผิดซ้ำโดยไม่ตรวจสอบ เราสามารถบันทึกสิ่งที่เกิดขึ้น ทดลองแนวทางใหม่ และขอความคิดเห็นจากผู้มีประสบการณ์ได้ กระบวนการเหล่านี้ช่วยเปลี่ยนเหตุการณ์ที่ไม่น่าพอใจให้กลายเป็นบทเรียนที่นำไปใช้ได้จริง

ดังนั้น ความผิดพลาดจึงไม่ใช่จุดสิ้นสุดของความพยายาม หากเราใช้มันเป็นข้อมูลสำหรับการปรับปรุง เราจะมีความรอบคอบและมั่นใจมากขึ้น การยอมรับข้อผิดพลาดอย่างรับผิดชอบจึงเป็นทักษะสำคัญของผู้เรียนและผู้ทำงานทุกคน

## Expected formatting

- กระดาษ A4
- ฟอนต์ไทยที่ระบุในคำขอ เช่น TH SarabunPSK หรือ TH NiramitIT๙
- เนื้อหา 16 pt และระยะห่างบรรทัด 1.5 ตามโปรไฟล์เริ่มต้น
- ชื่อเรื่องอยู่กึ่งกลางและเป็นตัวหนา
- เนื้อความจัดชิดขอบทั้งสองด้าน พร้อมย่อบรรทัดแรก
- ข้อมูลผู้เขียนอยู่ในส่วนท้ายกระดาษเมื่อมีการร้องขอ

## Verification probes

หลังสร้าง DOCX และ PDF ให้ตรวจอย่างน้อยดังนี้:

```bash
python docx_validate.py output.docx
pdfinfo output.pdf | grep -E 'Pages|Page size'
pdffonts output.pdf
pdftotext output.pdf output.txt
rg -n 'การเรียนรู้จากความผิดพลาด|ความผิดพลาดเป็นส่วนหนึ่ง' output.txt
pdftoppm -png -r 150 output.pdf preview/page
```

ผลที่คาดหวังคือไฟล์เปิดได้ ขนาดหน้าเป็น A4 ฟอนต์ไทยถูกฝังหรือถูก resolve อย่างถูกต้อง ข้อความไทยไม่กลายเป็นกล่อง และไม่มีหัวข้อร่างหรือ marker ที่ไม่ควรแสดงในเอกสารสุดท้าย
