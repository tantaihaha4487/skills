# Thai essay layout notes from this session

Historical example, not a default profile. Apply only when requested; otherwise follow SKILL.md and `document-structure-and-layout.md`.

- Default to **no visible section headings** in the final essay body when the user asks for a polished Thai essay, unless they explicitly request labels or an outline.
- Use a clean title-only top block; include supplied author/student details in the footer only when requested.
- The title/body font sizes used in this session were 18pt bold for the title and 16pt for the body.
- The resulting PDF should be checked for A4 sizing and embedded TH SarabunPSK via `pdfinfo` + `pdffonts`.
