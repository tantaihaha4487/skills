# Thai essay layout notes from this session

Historical preferences for school-style Thai essays for Thanachot. Use only when the current request calls for this style. Explicit requirements and the profile selection in SKILL.md take precedence.

- Title should be separate from author metadata.
- Put student name/ID/class details in a faint bottom-right footer or signature area when requested.
- Keep the final body as clean prose; no outline labels in the document unless explicitly asked.
- Prefer 3–5 paragraphs max for this style, and expand existing paragraphs instead of splitting into many short ones.
- If the user asks for a target word count, develop the argument while preserving the essay structure; add paragraphs when needed for readability.
- For one-page requests, follow the pagination guidance in `document-structure-and-layout.md`; preserve mandatory font sizes and margins.
- After conversion to PDF, verify embedded fonts with `pdffonts`.
